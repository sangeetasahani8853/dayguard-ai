# DayGuard — AI Real-World Action Agent

> **One-Line Pitch:** DayGuard is an AI real-world action agent that understands your schedule, your preferences, and what's happening around you—then decides and executes the next useful action.

Please refer to the main repository [README.md](../README.md) for full project documentation, architecture diagrams, setup instructions, and test verification results.

### Quick Start
```bash
# Run Streamlit Demo UI
streamlit run ui/streamlit_app.py

# Run FastAPI Backend Server
python app.py

# Run Test Suite
pytest tests/ -v
```
